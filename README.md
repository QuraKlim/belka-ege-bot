# Telegram-бот Бэлы Тимуровны

## Пользователи и статистика

При запуске через `npm start` бот сохраняет пользователей и действия в
`data/events.jsonl`. Путь можно изменить переменной `ANALYTICS_DIR` в `.env`.
Данные сохраняются между перезапусками. На сервере папка должна находиться на
постоянном диске; сохраняйте её при обновлении и делайте резервные копии.
Используйте один процесс бота на одну папку данных.

Учитываются каждый `/start`, команды `/materials`, `/useful`, `/help` (в том числе
из меню), все callback-кнопки и повторные проверки подписки. События записываются
до проверки подписки и отправки ответа: нажатие учитывается даже при отказе
в доступе или ошибке Telegram. Повторная доставка одного update не увеличивает
счётчики, новое нажатие той же кнопки увеличивает.

В журнале есть Telegram ID, username и имя пользователя, время действия (UTC),
ID чата и сообщения, команда или callback_data и подпись кнопки, если она
передана Telegram. Произвольный текст сообщений не сохраняется.

Посмотреть сводку на компьютере или сервере бота:

```powershell
npm run stats
```

Отчёт показывает уникальных пользователей, пользователей с `/start`, общее число
запусков, активных за последние 24 часа и 7 дней, число действий и уникальных
пользователей для каждой команды/кнопки. Полный JSON-отчёт со списком пользователей,
датами первого/последнего действия и числом запусков:

```powershell
npm run --silent stats -- --json
```

Статистика не публикуется в чате. Папка `data/` исключена из Git;
при выборе другой папки также исключите её из репозитория. Учёт начинается после
установки этой версии, предыдущая история не восстанавливается.

Ограничения Telegram: открытие меню без выбора команды и переходы по обычным
ссылкам/URL-кнопкам (включая «Подписаться») не присылают боту callback-события.
Команда, выбранная в меню, неотличима от введённой вручную и учитывается вместе
с ней. Подробнее: [Telegram Bot API](https://core.telegram.org/bots/api#inlinekeyboardbutton).

Бот реализует сценарий из `АЛГОРИТМ.docx`: выбор экзамена, проверку подписки на канал, выдачу материалов, план подготовки, диагностику и дополнительные полезности.

## Страница статистики

При `npm start` вместе с ботом запускается HTTP-сервер. В консоли появится полный
секретный адрес вида `http://localhost:3000/stats/<64 случайных символа>`.
Откройте его в браузере: таблица сгруппирована по пользователям, для каждого
показаны username (или имя/ID), Telegram ID, последняя активность и количество
нажатий каждой кнопки или команды. Повторные `/start` отображаются отдельным
счётчиком для каждого пользователя. Обновление страницы загружает свежие данные.

Ключ задаётся в `.env` как `STATS_TOKEN`: 64 символа из `0-9` и `a-f`.
Сгенерируйте случайный ключ командой и вставьте результат в `STATS_TOKEN`:

```powershell
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

Ключ обязателен для запуска бота и не меняется при перезапуске.
Без точного пути сервер возвращает 404; файлы данных через HTTP недоступны.
Ссылка даёт доступ к статистике любому, у кого она есть: не публикуйте её.
Для смены ссылки измените `STATS_TOKEN` в `.env` и перезапустите бота.
Старый файл `data/stats-token` больше не используется; для сохранения прежнего
адреса перенесите его содержимое в `STATS_TOKEN`.

Настройки в `.env`: `STATS_PORT=3000`, `STATS_HOST=0.0.0.0` (все интерфейсы).
Для доступа с другого устройства замените `localhost` в ссылке на IP или домен
сервера и разрешите порт в настройках хостинга/брандмауэра. Для доступа через
интернет настройте HTTPS через reverse proxy; при proxy на той же машине можно
задать `STATS_HOST=127.0.0.1`. Не сохраняйте секретный путь в публичных access-логах.
Само добавление эндпоинта не публикует компьютер в интернете.

## Запуск

### Поведение при сбоях и ограничения

Для уведомлений об ошибках укажите свой числовой Telegram ID в `.env`:
`ERROR_CHAT_ID=123456789`. Сначала нажмите `/start` у бота и перезапустите его после
изменения настройки. Пустое значение отключает уведомления.
Бот отправляет ошибки обработки событий, чтения статистики, проверки подписки
и предупреждения о недоступности Telegram при запуске. Не более одного
уведомления за 5 минут (остальные остаются в консоли), отправка не блокирует бота.
Токен бота и ключ статистики маскируются в уведомлениях. Блокировка бота обычным
пользователем не вызывает уведомление. При недоступности Telegram уведомления
тоже могут не доставляться; очереди повторной доставки для них нет.
Ошибки до инициализации уведомлений и аварийное завершение процесса остаются
в консоли и требуют внешнего мониторинга.

- Все запросы к Telegram, включая отправку файлов, имеют тайм-аут 60 секунд.
  При явном ответе 429 запрос повторяется не более двух раз с паузой `retry_after`
  ([Telegram API](https://core.telegram.org/bots/api#responseparameters)).
  Отправка после сетевого тайм-аута автоматически не повторяется: Telegram мог
  уже доставить сообщение. Пользователь может повторить команду или нажатие.
- Ошибка проверки подписки выводит просьбу повторить действие позже, а не
  сообщение об отсутствии подписки. Материалы при неизвестном статусе не выдаются.
- При ошибке записи статистики получение следующих событий приостанавливается
  до успешной записи. Незавершённый хвост записи удаляется перед повтором.
  Это рассчитано на один процесс: нельзя одновременно писать в журнал из двух копий.
- События обрабатываются последовательно: длительная отправка одному пользователю
  задерживает остальных. Для большой аудитории потребуется очередь обработки.
- Журнал растёт без автоматического удаления. Страница статистики читает его
  целиком; при большом объёме потребуется база данных с индексами и пагинация.
- Статистика нажатий не означает успешную доставку материалов. Незавершённая
  цепочка отправки не возобновляется после перезапуска; при аварии возможен
  повтор ответа на ещё не подтверждённое Telegram событие. Для строгих гарантий
  доставки нужна отдельная постоянная очередь исходящих сообщений.

### Установка

1. Установите Node.js 20 или новее.
2. Скопируйте `.env.example` в `.env` и вставьте токен от `@BotFather`.
3. Добавьте бота администратором канала `@Belkateacher`. Это необходимо, чтобы Telegram разрешил проверять подписку через `getChatMember`.
4. Запустите:

    ```powershell
    npm start
    ```

Внешние npm-пакеты не нужны.

## Файлы

Если доступны материалы из папки «Наполнение», положите их сюда:

- `assets/diagnostic.docx` — диагностический тест;
- `assets/oge-cheatsheets.pdf` — шпаргалки ОГЭ.

Если файла нет, бот не падает: он отправит пояснение и продолжит сценарий.

Команды: `/start`, `/materials`, `/help`.
